Version 2.12
- New: on first open, Game Mode now suggests (once) opening as administrator, so the Windows-tweak mods apply without asking for permission every time. It is only a suggestion — the program works normally without it, and you can turn it on or off any time in Options > "Ao abrir o programa".
- Confirmed: the installed program still never needs Python — Nuitka bundles everything inside GameMode.exe.

Versão 2.12

É só uma sugestão — o programa funciona normalmente sem isso, e dá para ligar ou desligar quando quiser em Opções > "Ao abrir o programa".
- Confirmado: o programa instalado continua não precisando de Python — o Nuitka embute tudo dentro do GameMode.exe.

Version 2.11
- Fixed: after opening the app from the tray icon, the window could reappear with no button on the Windows taskbar until you closed and reopened the whole program. It now forces the taskbar button back every time.
- Fixed: the "Windows para jogos" (win tweaks) mod could leave some of its 6 registry values changed and others not if one of them failed partway through Apply or Undo; it now rolls itself back automatically so it is always all-or-nothing. Undo is also more reliable if one of those settings already had an unusual value before you ever used the app.

Versão 2.11
- Corrigido: depois de abrir o programa pelo ícone da bandeja, a janela podia voltar sem nenhum botão na barra de tarefas, e só reaparecia certo se você fechasse e abrisse o programa de novo. Agora isso é forçado toda vez.
- Corrigido: o mod "Windows para jogos" podia deixar alguns dos 6 valores do registro trocados e outros não, se um deles falhasse no meio do caminho ao Aplicar ou Desfazer; agora ele desfaz sozinho o que já tinha mudado, para nunca ficar pela metade. O "Desfazer" também ficou mais confiável se algum desses ajustes já tinha um valor incomum antes mesmo de você usar o programa.
